Proceso: Registro de Pago

Flujo operativo del módulo Pagos en GESTION_COLEGIAL_ADM
Módulo: Pagos Actor principal: Cajero Sistemas: UI MVC + API Versión: 1.0

Actores

Cajero

Recibe el pago y registra la transacción en el sistema.

Sistema (UI)

Valida datos, calcula montos y envía al API.

API Externa

Persiste el pago y actualiza Cuentas por Cobrar.

Encargado / Alumno

Realiza el pago y recibe comprobante.

Pantallas involucradas

🖥 Account/Login.cshtml

Inicio de sesión del cajero.

🖥 Pagos/Index.cshtml

Listado principal con DataTable de pagos registrados y botón "Nuevo Pago".

🪟 Modal _CreatePago.cshtml

Formulario modal para selección de alumno, conceptos, descuentos y forma de pago.

🖥 CuentasCobrar/Index.cshtml

Se actualiza automáticamente tras registrar el pago (saldos pendientes).

🖥 Pagos/Recibo.cshtml

Vista de impresión del comprobante con número de recibo generado.

Notas técnicas

  • Endpoint del API: POST https://localhost:7076/api/v1/pagos
  • Controlador MVC: PagosController.CreateAsync
  • Servicio: PagosService → SendHttpClient.PostAsync
  • Actualización en cascada: CuentasCobrarService recalcula saldos pendientes
  • Validación de duplicados de recibo vía atributo [Remote]
